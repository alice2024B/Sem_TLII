# Mini generador léxico

## Descripción
Este programa es un pequeño analizador léxico realizado en lenguaje C.
El programa identifica dos tipos de tokens:
- Identificadores
- Números reales
  
## Reglas
Identificador: letra(letra|digito)*
Real: entero.entero+

#ejemplos
Identificadores: 
- variable
- contador1
- sumaTotal2 
Números reales:
- 10.5
- 25.75
- 3.1416
